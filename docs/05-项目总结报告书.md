## 1. 项目概述

校园二手拍卖与即时通讯平台（CAIP）是一个面向高校学生的Web应用，以实时英式拍卖模式实现公允的价格发现，以内置即时通讯(IM)替代第三方通信工具保护用户隐私，以校园身份认证构建可信交易环境。

**技术栈**：Spring Boot 3.4 + Vue 3 + TypeScript + MySQL 8.0 + Redis 7 + MyBatis-Plus 3.5 + Flyway + Docker

## 6. 经验教训

### 6.1 技术方面

1. **Redis 在拍卖中的关键作用**：Lua 脚本保证原子性，分布式锁防止定时任务重复执行，是并发场景的最佳实践
2. **WebSocket 的坑**：STOMP 的 `/user` 前缀和点对点推送需要通过 `convertAndSendToUser` 而非 Topic，容易用错
3. **MyBatis-Plus 自动填充**：createdAt/updatedAt 使用 MetaObjectHandler 比 SQL DEFAULT 更可靠
4. **前后端分离的 API 契约**：先定义统一响应格式（ResultVO/PageVO），前后端可以并行开发

### 6.2 管理方面

1. **CLAUDE.md 的必要性**：全局约束文件确保 6 人团队代码风格一致，减少了大量沟通成本
2. **Git 分支策略**：feat/<module> 独立开发确实减少了冲突，但合并时需要提前约定接口契约
3. **增量交付**：Sprint 1 优先核心功能（M1+M2+M3），Sprint 2 补完整功能，降低了风险
4. **文档与代码同步**：先写设计文档再写代码，确实减少了返工
